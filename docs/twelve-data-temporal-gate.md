# Garde temporelle Twelve Data

Cette garde distingue deux niveaux :

- contrôle ligne par ligne des timestamps `observedAt` et `availableAt` ;
- éligibilité scientifique de la source.

Même si les timestamps de chaque ligne sont cohérents, Twelve Data reste limité au développement tant que la disponibilité point-in-time, les révisions historiques, le survivorship bias et la licence de recherche ne sont pas vérifiés indépendamment.

Le jeu reste donc interdit pour la validation, le test final verrouillé, la validation externe et la production.
