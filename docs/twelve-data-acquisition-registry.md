# Registre d’acquisition Twelve Data

Ce registre transforme un rapport de smoke import borné en enregistrement reproductible : fournisseur, symbole, période demandée, date d’acquisition, nombre de lignes et empreinte SHA-256.

Il conserve volontairement les statuts suivants tant qu’ils ne sont pas démontrés :

- disponibilité point-in-time : non garantie ;
- contrôle du survivorship bias : non audité ;
- corrections historiques : non auditées ;
- licence de recherche : à vérifier selon le compte et les conditions applicables ;
- validation externe : non exécutée ;
- production : interdite.

Une acquisition peut servir au développement du pipeline, mais pas à une conclusion scientifique externe tant que les blocages restent ouverts.
