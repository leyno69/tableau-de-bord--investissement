# Approbation d'une release méthodologique

Une release ne peut être approuvée que si son manifeste est encore candidat, si la CI et les tests domaine sont au vert, si l'audit de chaîne est validé, si aucun blocage méthodologique n'est actif, si les limites sont documentées et si l'avertissement de non-conseil est présent.

Le mécanisme ne mesure pas la qualité scientifique des résultats. Il empêche uniquement de publier une version dont les contrôles obligatoires sont incomplets.
