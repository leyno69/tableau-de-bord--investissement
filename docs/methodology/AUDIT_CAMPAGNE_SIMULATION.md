# Audit d'une campagne de simulation

Une campagne n'est considérée comme terminée que si toutes les références de traçabilité existent, si tous les lots et toutes les réplications sont achevés, si les métriques et percentiles requis sont présents, et si les hypothèses, limites et avertissements sont documentés.

L'audit autorise uniquement une revue méthodologique. Il ne transforme pas une simulation en prévision, ne valide pas automatiquement la qualité scientifique du modèle et n'alimente pas l'IGL.
