# Registre des preuves LEYNOR

## Objectif

Le registre des preuves conserve les éléments qui soutiennent, contredisent ou ne permettent pas de trancher une conclusion.

Il est strictement séparé du niveau de confiance. La confiance mesure la robustesse méthodologique d’un résultat ; le registre des preuves inventorie la nature, la diversité et les limites des éléments disponibles.

## Types d’éléments

Le registre accepte notamment :

- simulations indépendantes ;
- données historiques ;
- sources externes ;
- reproductions ;
- validations hors échantillon ;
- contradictions.

Chaque élément précise :

- un identifiant unique ;
- la conclusion concernée ;
- son type ;
- sa direction `supportive`, `contradictory` ou `inconclusive` ;
- une référence et une empreinte de source ;
- la date d’observation ;
- la méthode ;
- l’observation ;
- le caractère reproduit indépendamment ;
- la validation hors échantillon ;
- les limites.

## Garde-fous

- un élément existant ne peut pas être écrasé silencieusement ;
- une empreinte de source ne peut pas être enregistrée deux fois ;
- les contradictions restent visibles et ne sont jamais annulées par un simple nombre supérieur d’éléments favorables ;
- une synthèse peut compter les directions, les reproductions et les validations hors échantillon, mais elle ne produit aucun niveau de preuve ;
- aucune pondération arbitraire n’est appliquée aux types de sources.

## Limites

Le nombre d’éléments ne démontre pas leur qualité ni leur indépendance. Une synthèse du registre ne constitue ni un niveau de preuve, ni un niveau de confiance, ni un IGL, ni une recommandation d’investissement.

Toute future classification du niveau de preuve devra faire l’objet d’un contrat, d’une calibration, de tests et d’une validation hors échantillon distincts.
