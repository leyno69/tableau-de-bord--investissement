# Contrat du niveau de preuve LEYNOR AI

## Objectif

Définir les conditions auditables qui doivent être réunies avant toute future classification du niveau de preuve d’une conclusion.

## Critères obligatoires

Chaque critère doit préciser :

- la méthode utilisée ;
- la règle d’acceptation ;
- l’observation ;
- la référence de calibration ;
- si le résultat a été reproduit indépendamment ;
- si un jeu de validation séparé a été utilisé ;
- si les contradictions ont été examinées ;
- un statut explicite ;
- les limites.

## Statuts

Les statuts autorisés sont :

- `satisfied` ;
- `unsatisfied` ;
- `not-evaluated`.

Une future classification du niveau de preuve reste bloquée si un critère n’est pas satisfait, n’est pas reproduit indépendamment, ne dispose pas de validation hors échantillon ou si les contradictions n’ont pas été examinées.

## Garde-fous

Ce contrat :

- ne calcule aucun niveau de preuve ;
- n’applique aucune pondération ;
- ne transforme pas le nombre d’éléments en qualité démontrée ;
- ne constitue pas un niveau de confiance ;
- ne constitue pas un IGL ;
- ne produit aucune recommandation d’investissement.

## Limites

La satisfaction des critères ne démontre pas automatiquement la causalité, l’indépendance complète des sources ni la généralisation hors du périmètre étudié.
