# Vue décisionnelle du niveau de preuve

Cette vue relie une classification versionnée à son explication traçable.

Elle affiche la synthèse, les références de preuve, les contradictions, les risques, les limites et les blocages éventuels. Un résultat `unclassified` indique explicitement que les éléments disponibles ne permettent pas une classification.

Cette vue ne transforme jamais le niveau de preuve en recommandation d’investissement et ne le confond ni avec le niveau de confiance ni avec l’IGL.
