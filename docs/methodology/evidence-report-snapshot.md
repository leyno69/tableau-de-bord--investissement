# Instantané de rapport du niveau de preuve

L’instantané fige les informations nécessaires à un rapport reproductible : version méthodologique, classification, explication, références, contradictions, risques, blocages et limites.

Il constitue une source structurée pour les futurs exports PDF et Excel. Aucun élément contradictoire ne doit être supprimé lors du rendu.

Le rapport décrit les éléments disponibles ; il ne constitue pas une recommandation d’investissement et ne remplace ni le niveau de confiance ni l’IGL.
