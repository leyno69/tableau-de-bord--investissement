# Manifeste de version méthodologique

Chaque version méthodologique de LEYNOR doit référencer le commit exact, les modules inclus, les documents applicables et les exécutions de validation.

Les statuts possibles sont `candidate`, `approved` et `withdrawn`. Une version ne peut être approuvée avec un blocage actif.

Le manifeste conserve les limites connues et un avertissement explicite : la méthodologie ne constitue ni une promesse de rendement ni une recommandation d'investissement.

Ce manifeste permettra de reproduire les rapports futurs et d'identifier précisément la méthode utilisée à une date donnée.
