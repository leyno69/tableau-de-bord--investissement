# Révocation des preuves

Une preuve peut être révoquée lorsqu'une source est retirée, que les données sont invalidées, qu'une méthodologie est remplacée ou qu'un problème d'intégrité est confirmé.

Chaque révocation est immuable, datée, attribuée à une autorité identifiée et assortie d'un motif explicite. Une preuve révoquée conserve son historique mais reçoit le blocage `evidence-revoked`.

La révocation interdit l'utilisation silencieuse de la preuve dans une nouvelle classification. Une preuve de remplacement peut être référencée, sans effacer la précédente.
