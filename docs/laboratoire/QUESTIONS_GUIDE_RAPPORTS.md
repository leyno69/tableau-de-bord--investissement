# Questions auxquelles répondent les rapports LEYNOR AI

Ce document définit un chapitre obligatoire des futurs rapports individuels et consolidés.

Chaque rapport devra expliquer clairement :
- les questions auxquelles les simulations permettent de répondre ;
- les hypothèses utilisées ;
- les limites ;
- les questions auxquelles il est impossible de répondre.

## Catégories

- Objectifs financiers
- Comportement de l'investisseur
- Résilience financière
- Diversification
- Risque
- Sensibilité des paramètres
- Robustesse des conclusions

Chaque section devra contenir des questions concrètes (ex. : "Que se passe-t-il si j'interromps mes versements ?") puis une explication des résultats et de leurs limites.

## Encadré obligatoire

Chaque chapitre se termine par :
"Décisions que ce rapport ne permet pas de prendre".

Le rapport ne doit jamais :
- prédire les marchés ;
- recommander un achat ou une vente ;
- promettre un rendement ;
- afficher un niveau de confiance, un niveau de preuve ou un IGL non justifiés empiriquement.

Ce document sert de référence produit pour toutes les évolutions futures du moteur de simulation et des rapports Premium.
